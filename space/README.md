# KökLM · Hugging Face Space

Bu klasördeki iki dosya (`app.py`, `requirements.txt`) bir Hugging Face Space'e (Gradio, ücretsiz CPU) yüklenir.
Space, KökLM'i bu repodan kurar ve Llama 3.2 1B Instruct ağırlıklarıyla canlı sohbet sunar.

- Varsayılan model: `unsloth/Llama-3.2-1B-Instruct` (erişim onayı gerektirmez).
- Resmi depo için Space ayarlarında `MODEL=meta-llama/Llama-3.2-1B-Instruct` değişkeni ve `HF_TOKEN` secret'ı eklenir.
